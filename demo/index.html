Satsuma · Pan & Zoom

Drag with the mouse and zoom with Ctrl + scroll wheel. On touchscreens, pan with one finger or zoom and pan with two. The orange marker stays clickable.

Try the controls

  • Desktop: Drag with the left mouse button. Hold Ctrl and use the scroll wheel to zoom in and out at the pointer.
  • Touch: Pan with one finger. Use two fingers to zoom and pan at the same time. Then lift one finger and keep dragging without a jump.
  • Interaction: Click or tap the orange marker. Dragging should not trigger a click.
  • Reset: The button below the map restores the initial view.

The map uses only HTML and CSS. You can use images, SVG or your own HTML content instead. This file needs no external images or services.

Use as an ES module

Give the viewport a fixed height and the content its natural size. The content must be a direct child of the container.

<div id="viewport" style="width: 100%; height: 400px">
    <div id="content" style="width: 1200px; height: 800px">
        Your content
    </div>
</div>
import {Satsuma} from './satsuma.js';

const viewer = new Satsuma(
    document.querySelector('#viewport'),
    document.querySelector('#content'),
);

// When removing the viewer:
viewer.destroy();

The optional third argument {scrollRequiresCtrlKey: false} enables wheel zoom without Ctrl. The default is true, allowing normal page scrolling without Ctrl. Touch gestures are unchanged.

Use dist/satsuma.js, or use the source files with their relative .js imports. Load ES modules over HTTP, for example with npm start.

Symfony AssetMapper

Copy dist/satsuma.js to assets/lib/satsuma.js. In your existing AssetMapper project:

// assets/app.js
import {Satsuma} from './lib/satsuma.js';

const container = document.querySelector('#viewport');
if (container) {
    new Satsuma(container, container.querySelector('#content'));
}
{# templates/base.html.twig #}
{{ importmap('app') }}

The Symfony project needs no npm build. Satsuma has no runtime dependencies. With Stimulus, create the viewer in connect() and call destroy() in disconnect().

Classic scripts / open directly

<script src="./dist/Satsuma.js"></script>
<script>
    const viewer = new Satsuma.Satsuma(container, content);
</script>

demo/index.html includes the library and example inline. Open this file directly, copy it or test it offline. Run npm run build to regenerate it after changes.

Zoom range: 0.1 to 8. Panning is unbounded. Avoid existing CSS transforms on the content and scaled or rotated ancestors. A current browser with Pointer Events is required.
