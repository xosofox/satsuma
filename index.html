Satsuma · Pan & Zoom

Maus ziehen und Mausrad drehen. Mobil: mit einem Finger verschieben, mit zwei Fingern zoomen und verschieben. Der orange Marker bleibt anklickbar.

Dein Inhalt. Dein Ausschnitt.
Bereit.

So testest du die Bedienung

  • Desktop: Mit der linken Maustaste ziehen. Am Mauszeiger mit dem Mausrad hinein- und herauszoomen.
  • Touch: Mit einem Finger verschieben. Mit zwei Fingern zoomen und gleichzeitig verschieben. Danach einen Finger anheben und ohne Sprung weiterziehen.
  • Interaktion: Den orangefarbenen Marker anklicken oder antippen. Nach einem Ziehen soll kein Klick ausgelöst werden.
  • Zurücksetzen: Der Button unter der Karte stellt den Ausgangszustand wieder her.

Die Karte besteht vollständig aus HTML und CSS. Du kannst stattdessen Bilder, SVG oder eigene HTML-Inhalte einsetzen. Diese Datei benötigt keine externen Bilder oder Dienste.

Verwendung als ES-Modul

Gib dem Ausschnitt eine feste Höhe und dem Inhalt seine natürliche Größe. Der Inhalt ist ein direktes Kind des Containers.

<div id="viewport" style="width: 100%; height: 400px">
    <div id="content" style="width: 1200px; height: 800px">
        Dein Inhalt
    </div>
</div>
import {Satsuma} from './satsuma.js';

const viewer = new Satsuma(
    document.querySelector('#viewport'),
    document.querySelector('#content'),
);

// Beim Entfernen des Viewers:
viewer.destroy();

Verwende dafür dist/satsuma.js. Alternativ kannst du die Quelldateien mit ihren relativen .js-Imports verwenden. ES-Module über HTTP laden, beispielsweise mit npm start.

Symfony AssetMapper

Kopiere dist/satsuma.js nach assets/lib/satsuma.js. In deinem bestehenden AssetMapper-Projekt:

// assets/app.js
import {Satsuma} from './lib/satsuma.js';

const container = document.querySelector('#viewport');
if (container) {
    new Satsuma(container, container.querySelector('#content'));
}
{# templates/base.html.twig #}
{{ importmap('app') }}

Im Symfony-Projekt ist kein npm-Build nötig. Satsuma hat keine Laufzeit-Abhängigkeiten. Bei Stimulus: in connect() erzeugen und in disconnect() mit destroy() aufräumen.

Ohne Modulsystem / direkt per Doppelklick

<script src="./dist/Satsuma.js"></script>
<script>
    const viewer = new Satsuma.Satsuma(container, content);

demo/index.html enthält die Bibliothek und das Beispiel bereits inline. Du kannst diese Datei direkt öffnen, kopieren und offline testen. Nach Änderungen erzeugt npm run build sie neu.

Skalierungsbereich: 0,1 bis 8. Verschieben ist unbegrenzt. Keine vorhandenen CSS-Transforms auf Inhalt oder skalierten/rotierten Vorfahren verwenden. Aktuelle Browser mit Pointer Events werden vorausgesetzt.
